# OruSchools Driver (mobile-driver)

Offline-first Flutter app for transport drivers. **Scaffold only**: a themed placeholder screen; features arrive in Phase 5 (see `documentation/implementation_plan.md`).

- Application id / bundle id: `com.oruschools.driver` · display name "OruSchools Driver"
- Theme: `OruTheme.light(density: OruDensity.driver)` from `packages/flutter-core` (light only, ADR-0005); 64px controls (Driver Safety density)
- Config: no `.env`; pass **public** values at build time with `--dart-define` (never secrets): `documentation/environment.md`
- Launcher icons: sources in `assets/icon/` (from `documentation/brand-assets`), generated by `dart pub global run flutter_launcher_icons -f flutter_launcher_icons.yaml`

```bash
flutter pub get            # from the repo root (pub workspace)
melos run analyze && melos run test
flutter run -d <device>    # from this directory
```
Android/iOS builds have not been verified on the setup machine (no Android toolchain / incomplete Xcode).
