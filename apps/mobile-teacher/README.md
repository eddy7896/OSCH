# OruSchools Teacher (mobile-teacher)

Offline-first Flutter app for Teachers. **Scaffold only**: a themed placeholder screen; features arrive in Phase 4 (see `documentation/implementation_plan.md`).

- Application id / bundle id: `com.oruschools.teacher` · display name "OruSchools Teacher"
- Theme: `OruTheme.light()` from `packages/flutter-core` (light only, ADR-0005); 48px minimum touch targets
- Config: no `.env`; pass **public** values at build time with `--dart-define` (never secrets): `documentation/environment.md`
- Launcher icons: sources in `assets/icon/` (from `documentation/brand-assets`), generated by `dart pub global run flutter_launcher_icons -f flutter_launcher_icons.yaml`

```bash
flutter pub get            # from the repo root (pub workspace)
melos run analyze && melos run test
flutter run -d <device>    # from this directory
```
iOS: built and run on the iOS 27 simulator (`flutter build ios --simulator`, then `xcrun simctl install booted build/ios/iphonesimulator/Runner.app` and `xcrun simctl launch booted com.oruschools.teacher`). Xcode 27 has no `Simulator.app`; open `DeviceHub.app` from `Xcode.app/Contents/Applications` to see the device. Android builds are not verified yet (needs the Android command-line tools and licenses).
