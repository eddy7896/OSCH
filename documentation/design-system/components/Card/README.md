# Card

The basic container for a group of related information.

**Provide:** `children`, optional `title`, `subtitle`, `icon`, `action` (usually a `LinkAction` “View all”), `tone="brand"` for the identity strip.

- One idea per card. If a card needs two headings, make two cards.
- Cards sit on `bg` with a `space-4` gap. Do not nest cards.
- “View all” goes top-right in `primary-text`.
