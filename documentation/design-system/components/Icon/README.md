# Icon

Draws one icon from the OruSchools outline set: 24px grid, round caps, 1.9px stroke, `currentColor`.

**Provide:** `name` (see the preview), optional `size` (16 / 20 / 24 / 32 — `icon-sm`, `icon-md`, `icon-lg`), and `label` only when the icon stands alone and means something.

- Always pair an icon with a word in navigation, statuses and buttons. Icon-only buttons are allowed only for back, close and search, and need `aria-label`.
- Icons take the colour of their text. Never colour an icon differently from the word next to it.
- Do not use emoji in product UI.
