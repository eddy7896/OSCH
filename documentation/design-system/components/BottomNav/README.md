# BottomNav

The main navigation of every mobile app.

**Provide:** `items` (`{key, label, icon, badge?}`), `active`, `onChange`.

- Fixed tabs per app: Teacher `Today | Classes | Messages | More`; Staff `Home | Attendance | Tasks | More`; Parent `Home | Academics | Messages | Payments | More`; Driver `Today | Routes | More` (hidden in Active Route Mode).
- Always icon + label. 3–5 items.
