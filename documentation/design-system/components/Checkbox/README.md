# Checkbox

A tick box with a label, used for to-do items and multi-select lists.

**Provide:** `label`, optional `description`, `checked` / `defaultChecked`, `onChange`.

- The whole row is tappable (48px tall). Done items are struck through and muted.
- For a single on/off setting that applies at once, still use a checkbox — the system has no switch, to keep one pattern.
