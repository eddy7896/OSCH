# Badge

A short label or a count.

**Provide:** `children` + `tone` (`success`, `warning`, `danger`, `info`, `brand`, `neutral`), optional `dot`; or `count` for the red unread counter (shows 99+ above 99).

- Badge words are one or two: “Pending”, “Active Route”, “In 25 mins”.
- Count badges only on nav items and the bell. Never on content.
